# Product Preview Card Component

A responsive product preview card featuring Gabrielle Chanel perfume. This project was built as part of a Frontend Mentor challenge using HTML and CSS.

## Built With

- HTML5
- CSS3
- Flexbox
- Media Queries
- Google Fonts

## Features

- Responsive layout for desktop and mobile devices
- Different product images depending on screen width
- Custom typography using Google Fonts
- Styled product pricing and Add to Cart button
- Hover effect on the button

## What I Learned

While building this project, I practiced:

- Creating layouts using CSS Flexbox
- Using media queries for responsive design
- Switching images with the HTML `<picture>` element
- Working with custom fonts
- Styling buttons and interactive elements
